# 百怪町（ひゃっかいまち）HYAKKAI MACHI

人のいない町で、都市伝説から逃げる一人称のホラーゲームです。スマホの横画面で遊べます（PC のブラウザでも動きます）。

- 第一怪｜廃病院 ― 口裂け女
- 第二怪｜ネオン街 ― テケテケ

## 遊び方

1. スマホのブラウザでこのページを開きます（iPhone は Safari、Android は Chrome がおすすめ）。
2. **ホーム画面に追加**すると、アプリのように全画面で遊べます。
   - **iPhone**: Safari の共有ボタン（四角から上向きの矢印）→「ホーム画面に追加」→「追加」
   - **Android**: Chrome の右上の ⋮ →「ホーム画面に追加」または「アプリをインストール」
3. 一度読みこむと、次からは保存した物から早く起動します（つながっていない所でも遊べます）。
4. 新しい版が出ると、次に開いた時に自動で入れかわります。

### 記録について

- 遊んだ記録は、この端末のブラウザの中にだけ保存されます（どこにも送りません）。
- iPhone では、**ホーム画面から遊んだ記録と、ブラウザ（Safari）で遊んだ記録は別々**になります。
- iPhone の Safari では、しばらく（7日ほど）開かないと記録が消えることがあります。ホーム画面に追加して遊ぶと消えにくくなります。

## ご注意

- **こわい表現があります**（暗い所・急に出てくる怪異・追いかけられる場面・こわい音）。血の表現はありません。
- 音が出ます。イヤホンをおすすめします。
- 個人情報の入力・広告・アクセス解析はありません。
